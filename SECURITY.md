# Security and safety boundary

This project must not collect or expose Discord credentials, tokens, message contents, private media, or account identifiers in source, logs, benchmarks, crash reports, or issue attachments.

Do not use self-bot behavior, credential extraction, DLL injection, code injection, anti-cheat bypasses, signature-check bypasses, or protocol changes intended to evade Discord controls. Do not weaken automatic updates or security checks to make a prototype easier to run.

Report suspected security issues privately to the repository owner. Do not open a public issue containing secrets or private user data.
